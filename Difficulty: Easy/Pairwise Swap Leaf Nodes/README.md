<h2><a href="https://www.geeksforgeeks.org/problems/exchange-the-leaf-nodes/1?page=2&category=Tree&sortBy=difficulty">Pairwise Swap Leaf Nodes</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18.6667px;">Given the <strong>root</strong> of a binary tree, <strong>swap</strong> the values of leaf nodes <strong>pairwise</strong> in left-to-right order and return the modified tree. If there is an odd number of leaf nodes, leave the last leaf unchanged.</span></p>
<p><span style="font-size: 18.6667px;">The driver code will print the modified tree in level order. For a node at index i:</span></p>
<ul>
<li><span style="font-size: 18.6667px;">Its left child is placed at index 2 * i + 1.</span></li>
<li><span style="font-size: 18.6667px;">Its right child is placed at index 2 * i + 2.</span></li>
<li><span style="font-size: 18.6667px;">If a child does not exist, 'N' is printed at that position.</span></li>
</ul>
