<h2><a href="https://www.geeksforgeeks.org/problems/is-the-doubly-linked-list-circular/1?page=2&category=Linked%20List,doubly-linked-list,circular-linked-list,circular%20linked%20list&difficulty=Easy,Medium,Hard&sortBy=difficulty">Check for Doubly or Circular</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;">Given head of a doubly linked list, check whether the linked list is circular or not.</span></p>
<p><span style="font-size: 18px;"><strong>Note:</strong> A value k is internally used by the driver code to construct circular or normal doubly linked list. k = 0 creates a non-circular list, while k = 1 creates a circular list by connecting the last node to the head.&nbsp;</span><span style="font-size: 18px;">It is not passed to the function. </span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong style="font-size: 18px;">Input: </strong><span style="font-size: 18px;">head = 2 &lt;-&gt; 4 &lt;-&gt; 6, k = 0<br><img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/930046/Web/Other/blobid0_1785824382.png" width="447" height="97"><br></span><strong style="font-size: 18px;">Output: </strong><span style="font-size: 18px;">false<br><strong>Explanation:</strong> The doubly linked list is not circular, as the last node (6) does not connect back to the head node (2).</span></span></pre>
<pre><span style="font-size: 18px;"><strong style="font-size: 18px;">Input: </strong><span style="font-size: 18px;">head = 4 &lt;-&gt; 6, k = 1 <br><img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/930046/Web/Other/blobid2_1785847418.png" width="240" height="92"><br></span><strong style="font-size: 18px;">Output: </strong><span style="font-size: 18px;">true<br><strong>Explanation:</strong> The doubly linked list is circular, as the last node (6) connects back to the head node (4).</span></span></pre>
